# DESIGN — 画面・操作・UI 方針

## 画面一覧

v1 は **単一画面**。ファイル未読込のときだけ取り込みを促す状態を出し、読み込み後は練習画面に切り替わる。

| 状態 | 内容 |
| --- | --- |
| 空状態（ファイル未読込） | ドロップゾーン＋「ファイルを選択」。対応形式の案内 |
| 練習画面（ファイル読込済み） | メディア＋コントロール＋セクション一覧 |

## 練習画面レイアウト

左にメディアと再生コントロール、右にセクション一覧を置く 2 カラム。

```
┌─────────────────────────┬───────────────┐
│                         │ Sections      │
│      VIDEO / AUDIO      │ ▸ イントロ      │
│                         │ ▸ サビ前 0.8x   │
│                         │ ▸ ソロ   0.5x   │
│                         │ ▸ アウトロ      │
├─────────────────────────┤               │
│ ▶ ⏸  [====|=======] 1:23 │ [+ 現在位置で追加]│
│ Speed [──●──] 0.75x  ⟲ON │               │
│ 🔊 Vol [──●──] 80%        │               │
└─────────────────────────┴───────────────┘
```

- **メディアエリア**：動画はそのまま映像を表示。音声ファイルのときはファイル名と簡易インジケータを表示（波形は v1 では出さない）。
- **トランスポート**：再生 / 一時停止、シークバー、現在時刻 / 総時間。シークステップ変更（1〜30 秒、デフォルト 5 秒）と ← → ボタンも並べる。
- **シークバー**：バー上に各セクションを **色帯（マーカー帯）** で重ねて、区間の位置を一覧できる（v1 未実装）。
- **速度コントロール**：プリセットボタン（0.5 / 0.75 / 1 / 1.25x）＋スライダー（0.25〜1.5x、0.05 刻み）＋数値表示。音程は常に維持。
- **音量コントロール**：スライダー（0〜100%）＋ミュートトグルボタン（スピーカーアイコン）。グローバル設定として localStorage に保存。セクションごとには保持しない。
- **ループトグル（⟲）**：ON のときだけアクティブ区間を反復。OFF なら通し再生（v1 未実装）。
- **セクション一覧（右）**：登録済み区間を縦に並べ、名前と（あれば）速度を表示。クリックで選択。リネーム・削除も提供。「現在位置で追加」で新規区間を作る。

## 主要操作フロー

### 1. ファイルを開く
ドロップ or 選択 → `URL.createObjectURL()` で `<video>`/`<audio>` に渡す → 同一ファイルの保存設定があれば復元。

### 2. セクションを作る
区間は **波形ドラッグではなく数値ベース**で作る（v1）。

1. 再生しながら開始したい位置で「A をセット」（現在の `currentTime` を start に）
2. 終了したい位置で「B をセット」（現在の `currentTime` を end に）
3. 必要なら数値で start / end を微調整、名前を付ける

> 「+ 現在位置で追加」は、まず現在位置を起点に短い区間を作り、その後 A/B を調整する導線でもよい。詳細導線は実装時に詰める。

### 3. 区間を練習する
セクションをクリック → **A へシークして即再生**。ループトグルが ON なら B に達するたび A に戻り、明示的に止めるまで反復。

### 4. 速度を合わせる
速度スライダーで調整。セクション選択中の変更は **そのセクションの speed として保存**。未選択（自由再生）中の変更は **グローバル速度** に保存。セクションを選ぶと、そのセクションの speed が適用される。

## キーボードショートカット

| キー | 動作 | 備考 |
| --- | --- | --- |
| `Space` | 再生 / 一時停止トグル | 入力欄・ボタン・リンクにフォーカス中は無効 |
| `←` | seekStepSeconds 秒戻る | |
| `→` | seekStepSeconds 秒進む | |
| `↑` | 音量を 5% 上げる | |
| `↓` | 音量を 5% 下げる | |

ショートカットはファイルを読み込んでいる間のみ有効。入力欄（テキスト・数値・select 等）にフォーカスが当たっているときは無効化し、セクション編集時の誤操作を防ぐ。

## UI トーン

- 練習中に集中できる、**情報を詰め込みすぎない落ち着いたトーン**。
- 操作は「開く → 区間を選ぶ → 速度を変える」が迷わずできることを最優先。
- **ダーク / ライト切り替えトグルを AppHeader に配置**。デフォルトはダーク（映像・長時間視聴と相性が良い）。

## コンポーネント設計のルール

- **表示と状態を分ける**：再生位置のような高頻度更新は再生エンジン側（`usePlayer`）に閉じ込め、UI コンポーネントは必要な値だけ購読する（詳細は [ARCHITECTURE.md](./ARCHITECTURE.md)）。
- **1 コンポーネント 1 責務**：`MediaStage` / `Transport` / `SpeedControl` / `SectionList` / `SectionItem` のように関心ごとに分割。
- **セクションは配列で扱う**：UI は常に「区間の配列」を前提に書く（v1 から複数対応）。
- **永続データと表示状態を混ぜない**：保存対象（区間・速度）と、純粋な見た目の状態（開閉等）を区別する。
