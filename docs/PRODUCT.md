# PRODUCT — Sound Studio とは

## 一言でいうと

ローカルの動画・音声を取り込み、**速度を落としても音程を保ったまま**、特定の区間を繰り返し再生できる**音楽練習サポートツール**。

DAW（作曲・編集）でも、録音メモでも、サンプラーでもなく、**「既にある音源を使って練習する」ためのプレーヤー**である。

## 解決したい課題

楽器の練習・耳コピでは、

- 速いフレーズを **ゆっくり** 聴きたい（が、音程は変えたくない）
- 難所だけを **何度も繰り返し** たい
- 曲を **区間に分けて** 部分練習で攻略したい
- 区間ごとに **ちょうどいいテンポ** が違う

という要求がある。一般の動画／音楽プレーヤーはこれらを満たさない。Sound Studio はこの一点に特化する。

## 想定ユーザー

- 楽器・歌の練習をする人（まずは作者自身／個人利用）
- 手元に練習用の動画・音声ファイルを持っている人

マルチユーザー・アカウント・共有は対象外（個人がブラウザ内で使うツール）。

## 主要ユースケース

1. 練習したい曲のファイルを開く
2. 全体を聴いて、練習したい区間（イントロ、サビ前のフレーズ、ソロ等）を登録する
3. 区間を選ぶ → その区間の頭から再生が始まり、繰り返しループする
4. 区間ごとに速度を落として、弾ける速さから徐々に上げていく
5. 翌日また同じファイルを開くと、登録した区間と速度が復元されている

## v1 で作るもの

- ローカルの **動画／音声ファイル** の取り込み（D&D／ファイル選択）
- 再生 / 一時停止 / シーク
- **再生速度の調整**（音程維持 = `preservesPitch`）
- **名前付きセクション**（練習区間）を複数登録・選択・リネーム・削除
- セクションの **区間ループ**（B に達したら A に戻る）
- **セクションごとの速度**保存（＋未選択時用のグローバル速度）
- 設定の **localStorage 保存／復元**（同じファイルを開き直すと復元）

## v1 で作らないもの（意図的な非対象）

| 機能 | 理由 | 行き先 |
| --- | --- | --- |
| 波形表示 | デコード・描画コストが高く、複雑さを避けるため | future |
| キー変更（移調 / pitch shift） | 標準 API になく Web Audio 上の自前実装が必要 | future |
| ループ回数指定 | 無限ループで核心価値は満たせる | future |
| ファイル本体の保存（アプリ内ライブラリ） | 動画は大容量。設定の記憶が本体価値 | future |
| URL（YouTube 等）取り込み | 速度・区間ループの精度を満たせない／規約 | future |
| マルチトラック・録音・編集・書き出し | これは DAW であり本アプリの目的外 | 対象外 |

詳細な優先順位は [ROADMAP.md](./ROADMAP.md) を参照。

## 判断軸（迷ったときの原則）

1. **練習に効くか**で判断する。「作る」「編集する」機能は本アプリの範囲外。
2. **すぐ動くこと**を優先する。重い技術検証（デコード・自前 DSP）が必要なものは future へ送る。
3. **設定の記憶こそ価値**。ファイルそのものの管理より、区間と速度を覚えていることを重視する。
