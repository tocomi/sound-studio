# ROADMAP

機能の優先順位と、これから決める／検証することの軽い地図。

## v0 — まず動く土台

最初の動作確認を取るための最小実装。

- [x] ローカルファイルの取り込み（ファイル選択だけでも可）→ `<video>`/`<audio>` で再生
- [x] 再生 / 一時停止 / シーク
- [x] 再生速度スライダー（`playbackRate` + `preservesPitch = true`）

ここまでで「速度を落として音程を保ったまま再生」という核心が動く。

## v1 — 練習ツールとして使える

- [x] ドラッグ＆ドロップ取り込み + 空状態の UI
- [x] 動画／音声 両対応、音声時のメディアエリア表示
- [ ] **名前付きセクション**の追加 / 選択 / リネーム / 削除（複数）
- [ ] セクションの**区間ループ**（B→A、ループ ON/OFF トグル）
- [ ] セクション選択で **A へシーク＆即再生**
- [ ] **セクションごとの速度** + 未選択時のグローバル速度
- [ ] シークバー上の**セクションマーカー帯**
- [ ] **音量スライダー + ミュートトグル**（0〜100%、グローバル保存）
- [ ] **localStorage 保存／復元**（キー = `size + lastModified`）

## future — 余裕が出たら

優先度の目安は上から高い順。

- [ ] **波形表示**（Web Audio `decodeAudioData` → ピーク間引き → canvas）
- [ ] **波形上のドラッグで区間作成 / 編集**（波形が前提）
- [ ] **キー変更（移調 / pitch shift）**（SoundTouch.js 等を Web Audio に組む）
- [ ] **ループ回数指定**（n 回で停止）
- [ ] ファイル本体を **IndexedDB に保存**してアプリ内ライブラリ化
- [ ] **URL（YouTube 等）取り込み**（精度・規約の制約を要検討）
- [ ] カウントイン / メトロノーム、区間前後のプリロール

## 対象外（やらないと決めたこと）

- マルチトラック編集・ミックス・録音・書き出し（＝ DAW の領域。本アプリの目的外）
- マルチユーザー / アカウント / 共有

## 未決定事項

- セクション作成の具体導線（「+ 現在位置で追加」後の A/B 調整 UX）

## 決定済み事項（実装で確定）

- 速度スライダー：0.25〜1.5x、0.05 刻み。プリセットボタン（0.5 / 0.75 / 1 / 1.25x）を併設
- シークステップ：1〜30 秒の範囲でユーザーが変更可能（デフォルト 5 秒）
- テーマ：ダーク / ライト切り替えトグルを AppHeader に配置（ダーク基調デフォルト）

## 要技術検証（future に着手する前に確かめる）

- 大きい動画ファイルの **波形ピーク算出コスト**（デコード時間 / メモリ）。MediaElement と Web Audio の併用可否。
- 移調（pitch shift）のリアルタイム品質とブラウザ負荷。
- IndexedDB に大容量 Blob を保存する際の容量上限・パフォーマンス。
